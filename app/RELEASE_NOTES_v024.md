# Keystoria v0.24 — Every Key Opens a World

- Renames the umbrella game from Panic Protocol to **Keystoria** throughout current UI, metadata, app share text, demo attribution, install messaging, and documentation.
- Creates a custom vector key-and-storybook mark and favicon, plus an intentionally restrained new brand overlay. Individual story missions retain their themed palettes.
- Expands the homepage language to accurately describe all four modes and 24 original adventures.
- Removes stale top-level preview HTML fixtures from the distributable root (preserved under `docs/legacy-previews`).
- Includes a standalone, accessible static `portfolio/index.html` showcase (no pretend multiplayer functionality).
- Retains `panic.*` storage keys for **backward compatibility**; existing scores, preferences and linked videos do not get reset on upgrade at the same origin.
- Does not affect Lyric Lab flashing letter, backend missions, videos, scores, or room protocol.

**Release caution:** Keystoria was previously used as a name by unrelated parties. This is not a legal trademark clearance. Domain, handles, and registration need independent checks before commercial launch.
