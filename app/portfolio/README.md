# Keystoria — static portfolio showcase

This folder is a **complete standalone static page**. Publish its contents as the root of a static site, or copy the folder to your portfolio and link it.

- `index.html` / `styles.css` are all the page code.
- `assets/` contains the Keystoria mark, actual UI screenshot and lyric typing preview.
- No Python, Node, server, build step or remote API is required to serve this showcase.
- All navigation and call-to-action links are functional in-page anchors.
- The playable co-op app requires the Python/WebSocket server from the parent project folder. A public game URL is deliberately not claimed here.
- If you later host the full game or publish its source, add those links to the hero/button area; make sure the playable server is secure and available before advertising a live demo.
- Check music/video licensing and trademark issues before a broader public or commercial release.

For complete installation / deployment information, see `../docs/PORTFOLIO_DEPLOYMENT.md` in the full source package.
